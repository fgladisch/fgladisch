## 🌿 Open-source agentic coding

I am an advocate of the **[Pi coding agent](https://github.com/badlogic/pi-mono/tree/main/packages/coding-agent)** and the broader adoption of **open-source agentic coding**.

That means I like developer tooling where:

- 🧩 agents use explicit, inspectable workflows instead of hidden magic
- 🧪 coding assistants verify changes with real commands and tests
- 🧠 LLMs become part of reproducible engineering systems
- 🔓 workflows, prompts, skills, and extensions stay open and hackable
- 👥 humans remain in the loop for judgment, review, and direction

LLMs are most useful when they become reliable collaborators inside transparent engineering processes — not opaque autocomplete boxes.
